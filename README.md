# Анализ транзакций интернет-магазина

Исследовательский анализ продаж, возвратов, клиентов и географии
интернет-магазина за период с 1 декабря 2018 года по 9 декабря 2019 года.


## Цель проекта

Изучить структуру продаж и возвратов, определить особенности клиентской
и географической концентрации выручки, а также сформулировать бизнес-гипотезы
для дальнейшей проверки.

## Основные результаты

- После очистки в анализе осталось **526 417 строк**.
- Валовая выручка составила **£62,78 млн**, сумма возвратов — **£2,66 млн**,
  чистая выручка — **£60,12 млн**.
- За исследуемый период зарегистрировано **19 790 заказов**.
- В данных идентифицировано **4 718 клиентов**.
- Великобритания формирует **83,38% выручки** и **90,49% заказов**.
- На 10% идентифицированных клиентов приходится **59,02% клиентской выручки**.
- Два товара с наибольшим количеством возвратов формируют
  **50,46% возвращённых единиц**.
- Товары стоимостью от £10 до £15 обеспечивают **82,07% выручки**.

Результаты имеют описательный характер и не доказывают
причинно-следственные связи.

## Что было сделано

- Отдельно рассмотрены продажи и возвраты.
- Рассчитаны валовая выручка, сумма возвратов и чистая выручка.
- Проанализирована динамика показателей по месяцам.

## Правила расчёта

- Продажами считаются строки с положительным количеством товара.
- Возвратами считаются строки с отрицательным количеством товара.
- Валовая выручка рассчитывается только по продажам.
- Стоимость возвратов рассчитывается по абсолютной стоимости возвращённых товаров.

Чистая выручка = Валовая выручка − Стоимость возвратов
